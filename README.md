# Universal Design for Learning (UDL) – Converted to Docsify-This

> The Pressbooks book [Universal Design for Learning (UDL) for Inclusion, Diversity, Equity, and Accessibility (IDEA) 2nd Edition](https://ecampusontario.pressbooks.pub/universaldesign2/), brought into Grav Open Publishing Space by the [Pressbooks Converter](https://pressbooks-converter.hibbittsdesign.org), then converted to plain Markdown pages for [Docsify-This](https://docsify-this.net/#/) by the [Open Publishing Course Space Bridge](https://open-publishing-course-space-bridge.hibbittsdesign.org).

View it as a website: https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-open-publishing-pressbooks-udl-site/main&homepage=home.md&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&pagination=true&searchbox=true&collapsibleSidebarGroups=true&collapseSidebarGroups=true

These pages are the bridge's output as it is, shown like the guide in Open Publishing Space: the home page is the Guides page, with a card for the book, and the book is in a folder of its own. The book's home page starts with its cover, title, author and licence, then a card for each module, the sidebar lists its modules and pages, and Previous/Next buttons follow the pages in order.

The original book is by Darla Benton Kearney, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Its Grav version is at https://demo.hibbittsdesign.org/variants/grav-open-publishing-quark2-pressbooks-udl – this version uses the same content:

- `home.md` – the Guides page
- `universal-design-for-2026/` – the book: `README.md` (its home page), its cover image, and a folder for each module
  - `section-1/` – Front Matter: about this guide, land acknowledgement, accessibility statement, preface, glossary and contributors
  - `section-2/` … `section-7/` – Modules 1 to 6, each with its overview (`README.md`) and pages

Only the book is converted – the Grav site's other pages, such as its blog and Read Me, stay there. Images stay on Pressbooks, as in the Grav version.

Each page also keeps its Grav settings in a hidden note at the top, so the bridge can turn these pages back into the same Open Publishing Space guide.
